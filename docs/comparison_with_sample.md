# Сравнение `Курсач.pdf`, методички и текущей реализации

## 1. Основа сравнения

Сравнение выполнено между:

- методическими указаниями `! МУ к КР по ТИЗИ 2026.pdf`;
- примером готовой работы `Курсач.pdf`;
- текущей реализацией приложения.

## 2. Что требует методичка

Методичка задаёт требования в трёх ключевых местах:

- раздел 2 `Постановка задачи`:
  обязательные таблицы, графики, модельные эксперименты и жадный алгоритм покрытия;
- раздел 3 `Варианты индивидуального задания`:
  правила выбора вариантов `N`, `J`, `K`, а также диапазоны `t=1..17`, `k=1..5`, `n=1..8`;
- раздел 5 `Содержание отчета`:
  фиксированная структура итогового отчёта.

Из этого следуют обязательные элементы реализации:

1. Таблица классификации отказов для 6 профилей атак.
2. Графики изменения вероятности отказа `pA(t)` для заданных атак.
3. Графики вероятности `P(p(t))` для одиночного тестирования.
4. Графики вероятности `P(p(t,k))` для коллаборационной стратегии.
5. Исследование влияния:
   - типа атаки;
   - `p(ai)`;
   - режимов `p(t)>0.5` и `p(t)<0.5`;
   - параметров `n`, `k`.
6. Жадный алгоритм покрытия на матрице `15x15`.
7. Отчёт по структуре:
   - введение;
   - постановка задачи;
   - краткие теоретические сведения;
   - разработка модели исследования;
   - структура и функции программной системы;
   - структура интерфейса;
   - сценарии экспериментов;
   - результаты исследования;
   - заключение;
   - библиографический список.

## 3. Что есть в `Курсач.pdf`

Из примера `Курсач.pdf` видно, что в нём:

- есть введение, постановка задачи, теория, модель, структура системы, интерфейс, сценарии, результаты, заключение;
- используются графики вероятности атаки и вероятности обнаружения;
- присутствует описание БД и классов;
- приводятся сценарии для нескольких экспериментов;
- есть отдельный раздел по результатам исследования.

При этом пример не является эталоном методики в полном смысле:

- в примере использованы свои вариантные данные;
- часть формулировок и таблиц адаптирована под конкретную реализацию;
- структура классов отличается от текущего приложения.

## 4. Что реализовано в текущем приложении

### 4.1. Реализовано

В текущем приложении есть:

- график `pA(t)` для выбранной атаки;
- эталонные профили `Лин_Н`, `Лин_С`, `Лин_В`, `Exp_Н`, `Exp_С`, `Exp_В`;
- усреднённый график по типам атак при `p(ai)=0.33`;
- таблица классификации отказов;
- график `P(p(t))` без противодействия;
- график `P(p(t,k))` без противодействия;
- график `p(ai) * pA(t)`;
- график `P(pA(t),p(t))` по формуле (8);
- график `P(pA(t),p(t,k))` по формуле (9);
- сравнительный график `Single / Collab`;
- таблица `P(p(t,k))` для текущего `p(t)`;
- генерация матрицы `15x15`;
- жадный алгоритм покрытия;
- отдельный блок по индивидуальным вариантам `2`, `5`, `9` с таблицей параметров и сравнительными графиками;
- пояснения к графикам и таблицам;
- документация по использованию;
- отчёт по структуре методички.

## 5. Что было добавлено относительно примера `Курсач.pdf`

По сравнению с примером были добавлены или уточнены:

1. Явное разделение графиков атаки и графиков эксперимента.
2. Пояснения к каждому графику с указанием используемой формулы.
3. Разделение базовых формул (1), (2) и формул с противодействием (8), (9).
4. Автоматическое формирование матрицы смежности и покрытия.
5. Отдельный отчёт по структуре из методички.
6. Отдельная документация по использованию приложения и тестированию.
7. Отдельное сопоставление с пунктом 3 методички по вариантам `2`, `5`, `9`, а не только с общей частью задания.

## 6. Что отсутствовало и чем закрыто

При сверке с методичкой и `Курсач.pdf` был заметен практический пробел:

- в реализации уже были общие справочные графики и таблицы;
- но не хватало явного блока, который напрямую связывает систему с индивидуальными вариантами из раздела 3 методички.

Этот пробел закрыт так:

- на странице атаки добавлен блок с вариантами `2`, `5`, `9`;
- показаны точные параметры линейных и экспоненциальных моделей из таблицы вариантов;
- добавлены отдельные графики для линейных и экспоненциальных профилей этих вариантов;
- рядом зафиксированы режимы `p(t)>0.5 = 0.75` и `p(t)<0.5 = 0.47` для варианта `2` из таблицы 2.
