# Руководство по использованию приложения

## 1. Назначение

Приложение реализует требования методических указаний
`! МУ к КР по ТИЗИ 2026.pdf` для темы:

`Разработка и исследование методов обнаружения компьютерных вторжений в интеллектуальных сетях`

Система позволяет:

- задавать параметры атак;
- запускать эксперименты по одиночному и коллаборационному тестированию;
- строить графики по формулам из методички;
- формировать таблицу классификации отказов;
- строить матрицу смежности `15x15`;
- искать покрытие жадным алгоритмом.

## 2. Основные формулы

### 2.1. Вероятность обнаружения при одиночном тестировании

Используется формула (1):

`P(p(t)) = p(t) * (1 - p(t))^(k - 1)`

Где:

- `p(t)` — вероятность однократного обнаружения уязвимости;
- `k` — номер теста или число повторений.

### 2.2. Вероятность обнаружения при коллаборационной стратегии

Используется формула (2):

`P(p(t), k, n) = C(n, k) * p(t)^k * (1 - p(t))^(n - k)`

Где:

- `n` — число устройств;
- `k` — число тестировщиков;
- `C(n, k)` — биномиальный коэффициент.

### 2.3. Учет противодействия

Для временных графиков эксперимента используются формулы (8) и (9).

Одиночное тестирование:

`P(pA(t), p(t)) = (1 - pA(t)) * p(t) * (1 - p(t))^(k - 1)`

Коллаборационная стратегия:

`P(pA(t), p(t, k)) = (1 - pA(t)) * C(n, k) * p(t)^k * (1 - p(t))^(n - k)`

В приложении:

- `pA(t)` моделируется выбранной атакой;
- при одной активной атаке берется частный случай
  `pA(t) = p(ai) * p(отк|Ai)`;
- `p(отк|Ai)` задается выбранным профилем атаки во времени.

## 3. Что находится на странице атаки

Страница атаки содержит графики, которые не зависят от параметров эксперимента `p(t)`, `p(ai)`, `n`, `k`.

### 3.1. График выбранной атаки `pA(t)`

Если атака линейная:

`pA(t) = a * t + b`

Если атака экспоненциальная:

`pA(t) = 1 - a * exp(-b * t)`

Этот график показывает только интенсивность противодействия во времени.

### 3.2. Эталонные профили отказа

Содержит кривые:

- `Лин_Н`
- `Лин_С`
- `Лин_В`
- `Exp_Н`
- `Exp_С`
- `Exp_В`

Они соответствуют таблице классификации ситуаций обнаружения отказов из методички.

### 3.3. Сравнение типов атак при `p(ai)=0.33`

Для линейных и экспоненциальных атак строится среднее значение по трем интенсивностям:

- низкая;
- средняя;
- высокая.

Вес каждой интенсивности равен `1/3`.

### 3.4. Вариант 1 по общему списку

Для студента с номером `I=1`:

- `N = (I mod 11) + 1 = 2`
- `J = ((I + 3) mod 11) + 1 = 5`
- `K = ((J + 3) mod 11) + 1 = 9`

То есть для таблицы вариантов атак нужно использовать:

- вариант `2`
- вариант `5`
- вариант `9`

Эти параметры используются при создании атак и запуске экспериментов.

### 3.5. Блок сравнения по вариантам `2`, `5`, `9`

На странице атаки дополнительно выведены:

- таблица параметров линейных и экспоненциальных моделей для вариантов `2`, `5`, `9`;
- отдельный график линейных профилей этих вариантов;
- отдельный график экспоненциальных профилей этих вариантов;
- напоминание о режимах из таблицы 2: `0.75` и `0.47`.

Этот блок нужен именно для прямой сверки с разделом 3 методички, где задаются индивидуальные варианты.

## 4. Что находится на странице эксперимента

Страница эксперимента содержит графики, которые зависят от введенных параметров:

- `p(t)`
- `p(ai)`
- `n`
- `k`
- выбранная атака

### 4.1. График `P(pA(t), p(t))`

Это одиночное тестирование с учетом противодействия.

Почему график изменяется по времени:

- `p(t)` фиксировано;
- `k` фиксировано;
- меняется `pA(t)`;
- значит меняется множитель `(1 - pA(t))`.

### 4.2. График `P(pA(t), p(t, k))`

Это коллаборационное тестирование с учетом противодействия.

Почему график изменяется по времени:

- `p(t)`, `n`, `k` фиксированы;
- меняется `pA(t)`;
- значит меняется итоговая вероятность обнаружения.

### 4.3. Таблица `P(p(t, k))` для диапазонов `n=[1..8]`, `k=[1..5]`

Это не временной график, а параметрическая таблица по формуле (2).

Она нужна для сравнения влияния числа устройств и числа тестировщиков.

### 4.4. Матрица смежности и жадное покрытие

Приложение:

- генерирует матрицу `15x15`;
- обеспечивает число связей в строке из диапазона `[1;6]`;
- строит покрытие жадным алгоритмом.

## 5. Как пользоваться приложением

### 5.1. Создание атаки

1. Открыть раздел `Атаки`.
2. Нажать `Создать атаку`.
3. Выбрать тип:
   `Линейная` или `Экспоненциальная`.
4. Ввести `a` и `b`.
5. Сохранить атаку.
6. Открыть страницу атаки и проверить график `pA(t)`.

### 5.2. Создание эксперимента

1. Открыть раздел `Эксперименты`.
2. Нажать `Запустить эксперимент`.
3. Выбрать созданную атаку.
4. Ввести:
   `p(t)`, `p(ai)`, `n`, `k`.
5. Сохранить эксперимент.
6. Открыть страницу результата и проверить:
   графики с учетом противодействия, таблицу `P(p(t,k))`, матрицу смежности.

## 6. Как тестировать вариант 1 по общему списку

### 6.1. Исходные данные

Для `I=1`:

- атаки: варианты `2`, `5`, `9`;
- вероятности однократного обнаружения: вариант `2` таблицы 2.

Из таблицы 2:

- `p(t)>0.5 = 0.75`
- `p(t)<0.5 = 0.47`

Диапазоны из методички:

- `t = 1..17`
- `k = 1..5`
- `n = 1..8`

### 6.2. Параметры атак для тестирования

#### Вариант 2

- линейная: `a=0.035`, `b=0.015`
- экспоненциальная: `a=0.8`, `b=0.045`

#### Вариант 5

- линейная: `a=0.05`, `b=0.03`
- экспоненциальная: `a=0.5`, `b=0.06`

#### Вариант 9

- линейная: `a=0.04`, `b=0.03`
- экспоненциальная: `a=0.7`, `b=0.08`

### 6.3. Рекомендуемый сценарий проверки

Для каждого из вариантов `2`, `5`, `9`:

1. Создать линейную атаку с параметрами варианта.
2. Создать экспоненциальную атаку с параметрами варианта.
3. На странице атаки проверить график `pA(t)`.
4. На странице атаки сверить форму графика:
   линейная атака должна быть прямой,
   экспоненциальная — возрастающей нелинейной кривой.

После этого для каждой атаки запустить минимум два эксперимента:

1. Высокая вероятность обнаружения:
   `p(t)=0.75`
2. Низкая вероятность обнаружения:
   `p(t)=0.47`

Рекомендуемые значения:

- `p(ai)=1.0` для проверки максимального влияния атаки;
- затем `p(ai)=0.33` для сценария из методички;
- `n=8`, `k=5` для максимально насыщенной коллаборации;
- дополнительно `n=5`, `k=3` как средний сценарий.

### 6.4. Что именно проверять в результатах

#### На графиках эксперимента

Нужно убедиться, что:

- графики не являются постоянными прямыми;
- при росте `pA(t)` вероятность обнаружения уменьшается;
- при `p(t)=0.75` значения выше, чем при `p(t)=0.47`;
- коллаборационный режим отличается от одиночного;
- при изменении `n` и `k` меняется таблица `P(p(t,k))`.

#### На матрице смежности

Нужно убедиться, что:

- размер матрицы равен `15x15`;
- в строках число связей находится в диапазоне `[1;6]`;
- жадный алгоритм возвращает набор строк покрытия.

## 7. Минимальный чек-лист для сдачи

Нужно показать:

- таблицу классификации отказов;
- графики `pA(t)` для атак;
- графики одиночного тестирования с учетом противодействия;
- графики коллаборационного тестирования с учетом противодействия;
- таблицу `P(p(t,k))` по `n`, `k`;
- матрицу смежности `15x15`;
- результат жадного покрытия;
- сценарий для варианта `I=1`, то есть для вариантов `2`, `5`, `9`.
